# Vectorized Gaussian Residual Computation

Vectorized version for flattened arrays

## Usage

``` r
compute_gaussian_obs_residuals_flat(Z_flat, Theta_flat, M_flat, m, p, Tt)
```

## Arguments

- Z_flat:

  Flattened observation array

- Theta_flat:

  Flattened theta array

- M_flat:

  Flattened M array

- m:

  Number of nodes

- p:

  Number of relations

- Tt:

  Number of time points

## Value

Sum of squared residuals
