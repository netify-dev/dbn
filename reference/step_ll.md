# Step Log-likelihood

Computes log-likelihood for one time step given regime

## Usage

``` r
step_ll(A, B, Theta_prev, Theta_curr, sigma2_proc)
```

## Arguments

- A:

  Sender effects matrix

- B:

  Receiver effects matrix

- Theta_prev:

  Previous Theta

- Theta_curr:

  Current Theta

- sigma2_proc:

  Innovation variance

## Value

Log-likelihood value
