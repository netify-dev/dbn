# Compute Gaussian Observation Residuals

Sum of squared residuals for sigma2_obs update

## Usage

``` r
compute_gaussian_obs_residuals(Z, Theta, M)
```

## Arguments

- Z:

  Observation array (for Gaussian, Z = Y)

- Theta:

  Latent mean array

- M:

  Baseline mean array

## Value

Sum of squared residuals
