# Extract Baseline Network for IRF

Extract Baseline Network for IRF

## Usage

``` r
extract_baseline(fit, draw_idx, n_row, n_col, p)
```

## Arguments

- fit:

  dbn model fit object

- draw_idx:

  Posterior draw index

- n_row:

  Number of sender nodes

- n_col:

  Number of receiver nodes

- p:

  Number of relations

## Value

Baseline network matrix
